# sybil reflection — 2026-06-23 — DOC-3201 timezone backfill

Session: hardening the `DOC-3201` unplanned-attendance timezone backfill data
migration (PR #26523). Work was iterated **in place on the human-owned branch**
`DOC-3201-fix-unplanned-attendance-timezone`, committed as `3c871d8d2f7`, and
verified by two rounds of Codex cross-vendor review (final pass: clean).

## What worked

- **Measurement over assertion.** When asked for a confidence level, handed over
  a read-only diagnostic query instead of defending an estimate. The data
  confirmed the corruption mechanism *and* exposed the real ~6-row false-positive
  cluster that justified the #3 guard.
- **Cross-vendor review earned its keep** — caught the #2 payroll TOCTOU window;
  final pass verified the cumulative delta with file:line citations.
- **Parallel dispatch** of independent tasks (drone #2 payroll guard ∥ explorer
  #3 mechanism) in a single wave, no contention.

## Friction & misses

1. **DST detour — medium.** Let an *unfiltered* diagnostic pool drive a new DST
   concern and dispatched an opus `explorer` to verify it — work the
   "not-locked-for-payroll, mid-June" invariant already dissolved. Took two human
   corrections before I cancelled it. Root cause: reasoned about the broadest set
   matching the corruption *shape* rather than the set the migration actually
   *acts on* (post payroll-filter). Cost: one wasted opus dispatch + two
   diagnostic round-trips.
2. **Skills don't fit "iterate in place on the human's branch" — medium.** The
   cross-review/fanout skills assume a sybil-owned worktree + its own PR + a
   `.sybil/registry.json` entry. This session the human owned the branch, there
   was no sybil PR, and no registry was used. Adapting the skill by hand was
   friction in both review rounds.
3. **Orchestrator can't run the deterministic gates — medium-low.** `mix format`
   was attempted ~3 times and timed out each time (no bootstrapped mix/Hex in the
   orchestrator shell; cold compile). Only concluded "rely on implementer-reported
   gates" after burning the cycles. The skill's gate step offers no fallback.
4. **Cancelled a worker but left its watchdog armed — low.** `sys_cancel_task` on
   the DST explorer didn't cancel its watchdog timer, which later fired stale. The
   operating rules cover cancelling the watchdog on the normal inbox wake, but not
   on the cancellation path.

## Suggestions (ranked)

1. **Re-ground investigations in the acted-on scope before chasing pool-level
   anomalies.**
   - WHERE: `skills/investigate/SKILL.md` (scope-discipline note)
   - KIND: skill prose (sybil authors directly)
   - ACTION: before raising a finding from a diagnostic over a *superset*, confirm
     it survives the filters the change actually applies; don't dispatch a worker
     on a concern a known invariant already removes.

2. **Add an explicit "in-place / human-owned branch" mode to cross-review.**
   - WHERE: `skills/cross-review/SKILL.md` (step 1 + Notes)
   - KIND: skill prose (sybil authors directly)
   - ACTION: document the improvised adaptation — diff via `git show <commit>` /
     working-tree capture, detached review worktree at the commit for context, and
     "no sybil PR/registry ⇒ deliverable is the commit; skip registry steps, hand
     the branch back to the human."

3. **Give the gate step a fallback when the orchestrator can't run mix.**
   - WHERE: `skills/cross-review/SKILL.md` (step 3)
   - KIND: skill prose (sybil authors directly); optional env bootstrap is a human
     decision
   - ACTION: "If the orchestrator environment can't run the gates, don't loop on
     it — rely on the implementer's reported `mix format`/`compile` result and have
     the reviewer focus on logic." Optionally bootstrap mix/Hex in sybil's shell.

4. **Cancel the watchdog when you cancel its worker.**
   - WHERE: `config.yaml` system-prompt, watchdog / failure-recovery section
   - KIND: config change (→ `fanout` + `cross-review`)
   - ACTION: extend "cancel the watchdog on the inbox wake" with "...and likewise
     when you `sys_cancel_task` a worker, cancel that wave's watchdog so it can't
     fire stale."
